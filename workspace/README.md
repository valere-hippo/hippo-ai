# Runtime Workspace

Hier liegen Laufzeitdaten, die nicht direkt Teil des Quellcodes sind.

## Struktur

- `projects/` - Projektordner mit Eingaben, Analysen und Exports
- `logs/` - Laufzeitprotokolle
- `audit/` - manipulationsarme Aktionsprotokolle
- `backups/` - ZIP-Sicherungen pro Projekt
- `state/` - App-Zustand, Indexe und Registry-Dateien
- `inbox/` - neue, noch nicht zugeordnete Dateien
- `cache/` - temporäre Arbeitsdaten
